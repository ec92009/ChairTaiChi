# Chair Tai Chi

A small static web app for guided chair tai chi practice at a desk.

Version: `v90.0`

Published URL: `https://ec92009.github.io/ChairTaiChi/`

UI: **Sunrise Editorial** (magazine layout, sequence rail, canvas overlay copy) with a **Day / Night** toggle in the top bar.

Open `index.html` in a browser, or run a simple local server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Archive
